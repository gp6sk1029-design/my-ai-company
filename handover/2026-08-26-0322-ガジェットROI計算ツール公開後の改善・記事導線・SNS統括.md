## 直近のユーザ指摘と、次にやる修正

ユーザーが「② 消耗品の削減効果」の入力欄を見て「ここの意味がよくわからない」と指摘。現在のラベルは以下。

- `現在の1回あたり費用`
- `変更後の1回あたり費用`
- `年間の交換・使用回数`

計算の意味は、例えば `（750円 − 350円）× 12回 = 年間4,800円の削減`。ただし「1回」が使用1回なのか交換1回なのか不明確。

### 推奨する文言修正

- `現在の1回あたり費用` → `現在の交換1回あたり費用`
- `変更後の1回あたり費用` → `変更後の交換1回あたり費用`
- `年間の交換・使用回数` → `年間の交換回数`
- 補足文を追加:
  `例：純正品750円 → 互換品350円、月1回交換なら年間12回`

「1個あたり」も候補だが、カートリッジ、フィルター、液体の詰め替えなどに広く対応するため「交換1回あたり」の方がよい。

### 修正手順

1. 上記ローカルHTML正本を `apply_patch` で修正
2. WordPress管理画面の固定ページID 1115をコードエディターで開く
3. ローカルHTML全体を `<!-- wp:html -->` と `<!-- /wp:html -->` で包み、本文を置き換えて保存
4. 本番ページで文言、スマホ表示、JavaScriptエラーなしを確認
5. 消耗品の例 `750円 → 350円、年12回` を入力し、年間4,800円の削減になることを検証

WordPressの公開編集は対外操作のため、新セッションでユーザーが「修正して」と明示したら、その指示を最終操作の承認として実行する。意味の説明だけを求められた場合は無断で修正しない。
