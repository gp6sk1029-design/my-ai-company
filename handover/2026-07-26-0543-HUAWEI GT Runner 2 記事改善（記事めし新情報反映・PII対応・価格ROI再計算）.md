## Drive画像をコンテキストを汚さず取得する方法（今回確立）
- Driveのサムネイル直リンク(`drive.google.com/thumbnail?id=`)は**非公開ファイルではHTMLが返り使えない**。
- 正解：**記事めしのGAS経由でディスクに直接保存**する。
```python
import sys; from pathlib import Path
sys.path.insert(0,'blog/scripts')
import article_from_meshi as m
m.download_image_to_local('<DriveFileId>', Path('保存先.png'))
```
- これで1.4MBの画像もmainのコンテキストを消費せず取得できた（Readで画像を読まないこと＝2000pxエラー防止の既存ルールとも整合）。
