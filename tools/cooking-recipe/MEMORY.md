## 成功パターン

### 体調不良メニュー機能追加（2026-04-30 セッション）
- **payload に新フィールドを足すだけ**で D1 同期も自動で動く（`members` ストアの payload は JSON 文字列保存のためALTER不要）。再現性のあるパターンとして今後の機能追加にも適用可
- **症状ヒント辞書はサーバー側に持つ**（クライアント露出させない）→ プロンプト改ざん耐性＋アプリ更新なしで辞書を追記できる
- **期間自動失効ロジックをクライアント側で実施**（`isHealthIssueActive`）→ サーバーには有効分のみ送るので、Geminiトークン削減＋古い設定の混入防止が両立
- **UIバッジを独立要素に分離**（名前入力欄に絵文字を埋め込まない）→ ユーザーが名前編集中に副作用ゼロ
- **健康家族と体調不良者が混在する時の方針をプロンプトに明記**：(a)アレンジで共通化 (b)無理なら別メニュー＋名前末尾に「（〇〇さん用）」、を AI に判断させる二段階方式
- **単体テストをBashで完結**（`node -e` で関数を抽出評価）→ jsdom等の追加依存なしでロジック検証

### 構築・設計（2026-04-27 セッション）
- **既存blog/pwa-cloudflareのファイル構成流用** → 構築時間半減（生産技術原則：再現性）
- **Gemini `responseSchema` でJSON強制** → パースエラー激減・後処理ロジック簡素化
- **家族メンバー個別管理** → 「子どもだけピーマン嫌い」などの細やかな対応を実現
- **複数枚画像の総合判断プロンプト** → 1枚では認識できない奥の食材も拾える
- **静的JSON（seasonal.json）採用** → Gemini呼び出し2倍→1倍にコスト削減
- **画像1280px縮小** → Cloudflare送信量・Visionコスト両方削減
- **Cloudflare D1 + last-write-wins + updatedAt** → コンフリクト処理がクリーン
- **3秒デバウンス同期** → 連続編集10回でも同期1回（リクエスト数1/10）
- **論理削除（deletedAt）** → 削除の伝播が確実
- **市販調味料の製品名カタログをプロンプト埋め込み** → メーカー名＋商品＋味まで明記された出力
- **食事別設定（朝5分/夜30分）** → AIが朝=ワンプレート・夜=定食と使い分ける
- **OAuth は GIS Token Client（implicit flow）** → サーバー不要・セキュア
- **Google連携の選択方式UI** → ユーザーが「どの献立/アイテムを同期するか」を完全コントロール

### 1週間プラン特化（2026-04-27 セッション）
- **プロンプトに「鶏2/豚2/牛1/魚2」のようなタンパク源配分を明記** → AIが素直に従う
- **デフォルトを1週間にする** → 「土曜にまとめ生成→日曜にまとめ買い→平日は迷わない」運用が定着しやすい
- **week-summary card で期間・食数・予算を一覧化** → 全体把握が早い

## 失敗パターン

### 構築時の落とし穴
- **ローカル http.server で /api/* をテストしようとした** → POST非対応で501エラー。Cloudflare Pages Functions の動作検証は `wrangler pages dev` か本番デプロイが必須。静的サーバーで確認できるのはUIだけと最初に明示すべき
- **名前入力欄に体調バッジ絵文字を埋め込んだ初期実装** → ユーザー編集中に絵文字が消える副作用が発生。UIフラグ系は必ず別要素に分離する（後で独立span要素に修正済み）
- **APIキーをチャット履歴に貼ってしまった** → ローテーション必要。今後は環境変数で受け渡し
- **Gemini が同じ dayIndex を別エントリで返すケースあり** → クライアント側で `normalizeGeneratedDays()` で統合する保険を実装
- **app.js が約2100行に肥大化** → SKILL.md の「500行で分割」ルール超過。Phase 2 でモジュール分割が必要
- **ディレクトリが `private/` から `tools/` に途中で移動した** → 引き継ぎ書のパス更新を忘れがち。CLAUDE.md「現在のプロジェクト一覧」と整合性チェック必須

- 既存 `blog/pwa-cloudflare` のファイル構成をそのまま流用できた（ムダ排除）

- 連続生成時のレイテンシ（7日×朝昼夜だと10〜30秒）→ UI の体感改善が必要なら Phase 2 でストリーミング
