# 学長メソッド研究ルール（digest）
# リベシティ学長等の発信を期間単位で収集・要約し、副業・生活改善の「考え方」を整理する

> ⚠️ このファイルは **学長コンテンツの要約・蓄積ルール** です。
> 収集の基本フロー（Chrome MCP・礼節）は [collect.md](collect.md)、掛け合わせは [synthesize.md](synthesize.md)、自動化は [automate.md](automate.md)、他部門連携は [handoff.md](handoff.md)。
> 全体像は [research/SKILL.md](../SKILL.md)。

---

## §0. このファイルの役割と読むタイミング

リベシティ学長（両学長）や信頼できる専門家の発信（学長マガジン・高配当株マガジン・動画・ライブ等）を要約するとき必読。学長マガジンと高配当株マガジンは、収集元・台帳・ビューアを分離する。

- **入力**: リベシティのログイン済みブラウザ + 学長発信コンテンツ
- **出力**: research/MEMORY.md「📰 学長メソッド蓄積台帳」「💰 高配当株メソッド台帳」
- **完了条件**: 自分の言葉での期間要約がビューアに反映され、対象期間と主要テーマが台帳に記録されている

---

## §1. 🚨 最重要：3つの絶対ルール（必ず守る）

| # | ルール | 理由 |
|---|---|---|
| 1 | **私的利用限定**。要約は自分の学習メモ。**blog/sns送出は禁止** | リベシティ規約#12（二次配布禁止）。学長マガジンは有料会員コンテンツの可能性が高く特にリスク大 |
| 2 | **本文転載禁止**。必ず自分の言葉で要約（**300字以内**） | 著作権配慮。コピペは規約・著作権の両方に抵触 |
| 3 | **投資助言はしない**。高配当株は「考え方の要約」と「自分の保有記録の可視化」のみ | 安全ルール＋automate §12。「買うべき・この配分に・買い時」は出さない |

> 🔴 §1のいずれかに反する出力は**作らない**。特にルール3は、ユーザーの金銭事故を防ぐ最重要ライン。

## §2. 収集対象

| 種別 | 内容 | 規約リスク |
|---|---|---|
| 学長マガジン | 学長の定期発信（お金の基本・考え方） | 有料→自分用メモのみ |
| 高配当株マガジン | 高配当株の考え方・銘柄分析・市況 | 有料→自分用メモのみ・投資助言化禁止 |
| 動画・ライブ | YouTube／リベ内ライブの要点 | 公開動画は出典明記で要約可 |
| その他専門家発信 | 信頼できる発信者のノウハウ | 都度規約確認 |

- 収集手段は **collect.md §2 のClaude in Chromeフロー準拠**（3秒間隔・分速10件以下／時間帯制限なし）
- 本文は会話に展開しない。要約だけ台帳へ（collect.md §7）

## §3. 要約フォーマット（学長メソッド）

### §3.0 対象期間と表示範囲

1. ユーザーが期間を指定した場合は、その期間だけを収集・要約する。
2. 期間指定がない場合は、実行日を終点とする**直近1か月**を対象にする。
3. `学長メソッド研究まとめ.html` は対象期間の内容へ毎回差し替え、全履歴を画面に蓄積しない。
4. 要約は主要テーマ5〜8件、代表Q&A3〜5件を目安とし、同種の話題は統合する。
5. `President-Tweet` だけを学長マガジンとして扱う。高配当株マガジンの投稿・モデルPF・銘柄分析は学長マガジンのビューアへ入れない。
6. `research/MEMORY.md` には対象期間・主要テーマ・更新日を1行で残す。既存履歴は監査用に保持するが、今後は全投稿の逐次蓄積を必須としない。

期間内の主要テーマを以下の構造で「📰 学長メソッド蓄積台帳」へ。**300字以内**・自分の言葉。

```yaml
- 取得日: YYYY-MM-DD
  種別: 学長マガジン / 高配当株マガジン / 動画 / ライブ
  テーマ: (1行)
  学長の主張: (要点を自分の言葉で3つまで)
  数値: (出てきた具体的な数字・基準)
  副業への示唆: (副業に使えるヒント・なければ「—」)
  投資の考え方: (高配当株系のみ・後述§4)
  自分のアクション: (自分が次にやること・任意)
  出典URL: (コンテンツのURL)
```

## §4. 高配当株メソッドの扱い（投資助言NGの線引き）

高配当株マガジンからは「**考え方・判断基準・リスク管理の原則**」を要約する。個別銘柄が出ても **事実として記録**し、推奨に変換しない。

| ⭕ やること（記録・整理・計算） | ❌ やらないこと（助言・推奨） |
|---|---|
| 学長の選定基準・考え方を要約 | 「だからこの銘柄を買うべき」 |
| 「学長は○○と言っていた」（事実の記録） | 「あなたはこの配分にすべき」 |
| 配当利回り・分散の**計算/可視化**（life-plan） | 「今が買い時」（タイミング助言） |
| 保有株の現状を見える化 | 売買の代行・発注 |

> 線引き：**「学長がこう考えている」（事実）はOK／「だからこうすべき」（助言）はNG**。最終判断は必ずユーザー自身。

「💰 高配当株メソッド台帳」へ蓄積：
```yaml
- 取得日: YYYY-MM-DD
  トピック: (例: 増配株の見極め方)
  学長の考え方の要点: (自分の言葉で)
  基準/数値: (配当性向○%以下 等、学長が示した基準)
  注意・リスク: (学長が挙げたリスク)
  出典URL:
  ※投資判断は自分で行う（このメモは助言ではない）
```

### §4.1 月次モデルポートフォリオの「差分記録」手順（2026-05-30確立）

学長の月次モデルポートフォリオ（「もし学長が、◯月から高配当株投資を始めるなら？」の図解）を月次で比較するとき：

| 手順 | 内容 |
|---|---|
| 1. 図は転載しない | 学長の図解画像は保存・公開せず、**読み取って当方が独自作図**（著作権配慮）。比較図は `research/reports/` にHTMLで出力 |
| 2. **銘柄コードで照合** | 銘柄名OCRはブレるので、4桁の**証券コードを正**として前月リストと突合（並び順も同じことが多い） |
| 3. **差分だけ作図** | 「追加◯件／除外◯件」を主役に。全銘柄一覧＋集計（PF配当利回り・年間配当）を併記 |
| 4. 不確実な数値は載せない | 個別利回り・投資割合は小さい図でOCR誤差が出る。確実な「コード・名称・セクター・並び・全体利回り」に絞り、取り切れない値は「図解の通り」と明記 |
| 5. 投資助言化しない | 差分は**事実の記録**（学長がこう変えた／変えなかった）。「だから買い替えるべき」は書かない（§4の線引き厳守） |

> 🔴 線引き：「**先月と同じ／◯◯を追加した**」（事実）はOK／「**だからあなたも入れ替えるべき**」（助言）はNG。
> 実例：2026-05-30に 第110回(4月)→第113回(5月) を比較 → 構成34銘柄は完全同一・入れ替え0件・PF利回り4.03%→4.16% を `research/reports/高配当株ポートフォリオ比較_4月vs5月.html` に作図（💰台帳#4）。

## §5. 副業ヒントの抽出 → synthesize / automate へ

学長メソッドから副業に使えるネタが見えたら：
- **掛け合わせ**できそう → [synthesize.md](synthesize.md)（A×B＝新副業）
- **自動化**できそう → [automate.md](automate.md)（4ゲート→4パターン）

## §6. 高配当株ポートフォリオ記録 → life-plan 連携

「自分の保有株の記録・可視化」は **life-plan に持たせる**（handoff.md §5参照）。役割分担：

| ファイル | 持つもの |
|---|---|
| research（digest） | 学長の**考え方**の要約 |
| tools/life-plan | 自分の**保有データ**の記録・可視化（年間配当・利回り・業種分散） |

- digestは「情報」、life-planは「データ」。両者を分けることで投資助言化を防ぐ
- life-plan拡張要望は handoff.md §5 のフローで `tools/life-plan/MEMORY.md`「🔬 research由来TODO」へ追記

## §7. 「今の学長の考え方」要約・解説モード

ユーザーが「学長の考え方を教えて／要約して」と聞いたら：

1. 「学長の考え方」と指定された場合は「📰 学長メソッド蓄積台帳」だけを参照する。「高配当株」と明示された場合だけ「💰 高配当株メソッド台帳」を参照し、両者を混在させない
2. 解説は**自分の言葉**で（本文転載しない）
3. 台帳の日付で**考え方の変遷**も追える（「以前は○○、最近は△△を強調」）
4. 蓄積が無いトピックは「まだ収集していない」と正直に答え、collect/digestで取得を提案

> 月次棚卸しで「今の学長スタンス・サマリー」を1段落で更新しておくと、解説が速い。

## §9. 失敗時の対処

| 失敗 | 対処 |
|---|---|
| 有料コンテンツを誤って外部送出しそう | §1ルール1で停止。自分用メモに留める |
| 要約が助言に寄ってしまう | §4の線引き表で「事実/助言」を再判定 |
| 本文をコピペしそうになる | §1ルール2。自分の言葉で書き直す |
