# research/ — リサーチ部門

## このフォルダの役割

**リベシティ（libecity.com）のノウハウ図書館を素材源**として、副業アイデアの創造と自動化提案を行う第5部門。
他4部門（blog・tools・sns・PDM）にネタ・案件を供給する **上流の "種"** の役割。

## 2つのコア機能

| 機能 | 出力 | 振り先 |
|---|---|---|
| **掛け合わせ創造**（synthesize） | A×B = 新副業アイデア | blog/sns/自分着手 |
| **自動化提案**（automate） | 単一記事 → Claude Code/PWA化案 | tools部門 |

## フォルダ構成

```
research/
├── SKILL.md ............... 部門の目次・モード判定
├── MEMORY.md .............. 記事台帳・アイデア台帳・自動化提案台帳・マイ副業ポートフォリオ
├── README.md .............. このファイル
└── skills/
    ├── collect.md ....... リベシティ収集ルール
    ├── synthesize.md .... 掛け合わせ創造ロジック
    ├── automate.md ...... 自動化提案ロジック
    └── handoff.md ....... 他部門連携フロー
```

## 起動方法

ユーザーが以下のいずれかのキーワードを発すると、リサーチモードが起動：
- 「リベシティ」「ノウハウ図書館」「収集」
- 「副業ネタ」「副業計画」「掛け合わせ」「新事業アイデア」
- 「副業自動化」「Claude Codeで」「PWA化」「ツール化したい」「自動で回したい」

詳細は `SKILL.md` の「モード判定キーワード」を参照。

## 工程フロー

```
1. 収集（collect）       — リベシティから記事を取得
2. 選別（5指標で優良判定）  — 60点以上を「優良」マーク
3. 統合創造 OR 自動化抽出  — synthesize.md or automate.md で出力生成
4. 他部門振り分け（handoff） — blog/sns/tools/life-plan へ送出
5. 台帳化（MEMORY.md）    — 全結果を記録
```

## 🚨 初回確認チェックリスト

researchセッションを**初めて起動する前**に、以下を必ず確認してください：

- [ ] リベシティの利用規約を最新版で確認した
- [ ] 以下5項目を `MEMORY.md` の「ユーザー承認記録」セクションに記録した：
  1. スクレイピング（自動取得）の許容範囲
  2. 二次配布（要約・引用）の制限
  3. 商用利用（ブログ記事化・SNS投稿）の可否
  4. アクセス頻度の上限（本SKILLは3秒間隔・分速10件以下を想定）
  5. 半年ごとの規約再確認日（次回確認予定日）
- [ ] Claude in Chrome 拡張がブラウザにインストールされ、ログイン済み

**未記録の状態では起動しません**（SKILL.md「起動前必須確認」参照）。
