# 記事修正ログ（個別の生ログ）

> 記事を修正するたびに `edit_logger.py` で1行追記される。
> 「なぜ直したか・何を学んだか」を残す（git diff だけでは意図が分からないため）。
>
> **3段昇格ルール**
> 1. ここ（`blog/edits/_log.md`）= 個別の生ログ（粒度細かい）
> 2. 同じ種別タグが2回以上 → `blog/MEMORY.md`「失敗パターン」表 or「進化ログ」へ昇格
> 3. 全社普遍ルール → `CLAUDE.md` / `blog/SKILL.md` へ昇格（既存エスカレーションルール準拠）
>
> 種別タグ例：`装飾` / `数値裏取り` / `宣言数整合` / `文体` / `画像` / `事実誤り` / `SEO` / `構成`
