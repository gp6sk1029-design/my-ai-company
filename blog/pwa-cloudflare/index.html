📖 スクショの貼付方法（クリックで開く）

🖥️ Mac の場合

  1. ⌘+Shift+4 でスクショ撮影
    ※ さらに Control を押しながら撮ると クリップボードに直接コピーされます
    → ⌘+Shift+Control+4 がおすすめ
  2. このPWA画面の 「📋 クリップボードから貼付」ボタン をタップ
    または、画面のどこか（テキスト入力欄以外）をクリックしてから ⌘+V
  3. 初回はブラウザから「クリップボード読取を許可」を求められます → 許可 を選択
  4. 「スクショ◯枚を貼付」のトーストが出れば成功 ✅

💻 Windows の場合

  1. Win+Shift+S でスクショ撮影 → 自動でクリップボードに入る
  2. このPWA画面の 「📋 クリップボードから貼付」ボタン をタップ
  3. あるいは画面の空きスペースをクリック → Ctrl+V

📱 スマホの場合

  1. 「📷 写真を撮る」ボタンが基本（カメラ起動）
  2. スクショは「🖼️ 選択」ボタン → 写真アプリから選ぶ

🖱 ファイルのドラッグ&ドロップ（PC）

  1. FinderやエクスプローラからPNG/JPGファイルを このPWA画面にドラッグ
  2. 青いオーバーレイが出たら離す → 自動で一時保存に追加

⚠️ うまくいかない場合：ブラウザの権限ダイアログを見落としていないか／URLバー横のカメラ・クリップボードアイコンで「許可」されているかをご確認ください
