# ガジェット系ブログ・X・YouTubeのPR／アフィリエイト運用分析

- 調査日: 2026-08-23
- 対象: 国内ガジェットブログ、ガジェット系X、ガジェットYouTube
- 目的: 生産技術ガジェット研究所（PTGL）の信頼・流入・収益を同時に伸ばす表示と導線を決める

## 結論

最適なのは、すべての投稿へ機械的に `#PR` を付ける方法ではない。読者との関係を次の5種類に分類し、**関係性をそのまま短く表示する**方法が最も誤解が少ない。

| 関係 | 表示 | 基本導線 |
|---|---|---|
| 自腹購入・収益リンクなし | 表示なし | 実測・写真・欠点を中心に発信 |
| 自腹購入・記事内に通常アフィリエイトあり | `※記事内にアフィリエイト広告を含みます` | X本文から記事へ。ブログ冒頭でも広告を明示 |
| Xに直接アフィリエイトリンク | `※アフィリエイトリンクです` | 商品名・選ぶ理由・欠点を本文内で完結させる |
| 商品提供・貸与・イベント招待 | `【提供：会社名】`。投稿依頼や表示内容への関与があれば `【PR／提供：会社名】` | 提供関係を本文上部に置き、長所・短所を併記 |
| 有償案件・指定投稿・特別施策 | `【PR】提供：会社名` | X本文上部、ブログ冒頭、動画内・概要欄・YouTube設定のすべてで明示 |

通常アフィリエイトで `PR` とだけ書くと、企業から金銭や商品提供を受けた案件だと誤解されやすい。一方、何も書かないとXの有料パートナーシップポリシーに抵触するおそれがある。**「PR」ではなく「アフィリエイト広告」と正確に書く**のが、法令・プラットフォーム・読者心理を最もきれいに両立する。

## 公式ルールの突き合わせ

### 消費者庁

- 事業者の依頼ではなく自主的な意思による投稿は「事業者の表示」に当たらず、`PR` は不要。
- 事業者の表示に当たるSNS投稿で、広告表示を返信だけに置くのは、通常は気付かれないおそれがある。
- アフィリエイトサイトは、冒頭に表示があるだけでなく、サイズ・色を含め実際に明瞭である必要がある。
- 動画は途中から視聴されるため、冒頭だけでなく動画全体を通して明瞭にすることが望ましい。

出典: [消費者庁「ステルスマーケティングに関するQ&A」](https://www.caa.go.jp/policies/policy/representation/fair_labeling/faq/stealth_marketing/)

### 楽天アフィリエイト

- 楽天アフィリエイトの基本機能だけを使い、広告主との直接・間接の情報交換や成果報酬以外の金品がない場合、広告表示は任意。
- 商品提供、イベント、アフィリエイター向けお試しクーポンなどは表示必須。
- 表示必須の施策はファーストビューで分かる位置に置く。

出典: [楽天アフィリエイト「ステルスマーケティング規制の対応」](https://affiliate.rakuten.co.jp/guideline/stealth_marketing_regulation/)

### X

- Xは、アフィリエイトリンクや割引コードからコミッションが生じる投稿も「有料パートナーシップ」に含めている。
- そのポストには「広告」「プロモーションコンテンツ」など、商用性が明確に分かる情報を含める必要がある。
- したがって日本法・楽天で表示が任意の通常アフィリエイトでも、X上では同じポスト内に `アフィリエイトリンク` または `記事内にアフィリエイト広告を含む` と書く運用が安全。

出典: [X「有料パートナーシップポリシー」](https://help.x.com/ja/rules-and-policies/paid-partnerships-policy)

### YouTube

- 有償プロダクトプレースメント、スポンサーシップ、企業から影響を受けたおすすめ情報はYouTube Studioで申告する。
- 通常アフィリエイトは概要欄のリンクより前に、紹介料が発生する可能性を明記する。
- 対象チャンネルでは、商品タグと概要欄リンクを併用する。YouTubeが公表する2024年の内部実験では、概要欄リンクだけよりクリックが23%増えたとしている。ただし関連商品だけをタグ付けする。

出典: [YouTube「有料プロダクト プレースメント、スポンサーシップ、おすすめ情報」](https://support.google.com/youtube/answer/10588440?hl=ja)、[YouTube Shoppingのヒント](https://support.google.com/youtube/answer/15814303?co=YOUTUBE._YTVideoType%3Dvideo&hl=en)

## 実例から分かったこと

実例は「その方法が法的に正しい」という証明ではなく、読者が実際に目にしている慣行の確認として扱った。判断は上記の公式ルールを優先する。

### X

| 発信者 | 観察した運用 | 学び |
|---|---|---|
| monograph／堀口英剛 | スポンサー投稿は冒頭に `【PR】`。通常のAmazonストア導線は案件投稿と区別 | 案件と自主紹介を同じラベルにしない |
| ものがま | Sony案件は `#PR` と提供会社名を明記。直接商品リンクは「アフィリエイトリンク」と表示 | `PR` と `affiliate` を言葉で分けると関係性が明瞭 |
| Gadgetouch | 記事告知は短い要点＋本文内リンク＋カードで完結 | ブログ流入が目的ならURLを必ず返信へ追いやる必要はない |
| 自動入荷・セール系アカウント群 | ほぼ同一のリンク投稿を短時間に連投。表示はあっても反応が極端に弱い例が多い | コンプライアンス表示だけでは価値にならない。連続リンク投下はPTGLでは採用しない |

参照: [monograph X](https://x.com/infoNumber333)、[ものがま X](https://x.com/MonoGamaaa)、[Gadgetouch X](https://x.com/gadgetouch)

### YouTube

| 発信者 | 観察した運用 | 学び |
|---|---|---|
| ワタナベカズマサ | 通常動画は概要欄にアフィリエイト広告を明記。案件は別に `提供：会社名` を上部表示 | 提供元と収益リンクを別々に開示 |
| monograph | 概要欄上部に `提供：会社名`、商品リンク、その後にアフィリエイト表示 | 視聴者がリンクを見る前に関係を理解できる順序 |
| ものがま | 商品リンクを「アフィリエイトリンク」と明記。頂き物も案件でなくても提供事実を説明 | 法的最低限より、誤解を減らす透明性を優先 |
| Gadgetouch | 提供元を明記しつつ、アフィリエイトリンクが含まれることも別途表示 | 企業案件と成果報酬を一文で曖昧にしない |

参照: [ワタナベカズマサ掲載動画一覧](https://yutura.net/channel/16895/latest/)、[monograph掲載動画](https://yutura.net/channel/17102/video/1TwK11GpgPY/)、[ものがま掲載動画一覧](https://yutura.net/channel/158971/popular/)、[Gadgetouch掲載動画](https://yutura.net/channel/76731/video/PfTj44pgIuw/)

### ブログ

| 媒体 | 観察した運用 | PTGLへ採用する点 |
|---|---|---|
| ガジェットショット | 実写を16:9に統一し、実機で気付いた不便・意外性を一次情報として蓄積。SNSでも一次情報を先出し | 実写、実測、作業手順、失敗点を記事とSNSの共通資産にする |
| ガジェマガ | アフィリエイトと企業案件を別収益として説明。メーカーより読者の信頼を優先し、提供品でも欠点を書く | 提供品でも結論を変えず、長所・短所を必ず併記 |
| ガジェ侍／UPDATE系方針ページ | 記事冒頭で広告を明示し、提供関係や編集の独立性を説明 | PTGLにも広告・レビュー方針ページを作り、各記事の表示を短くできるようにする |

参照: [ガジェットショットの運営解説](https://gadget-shot.com/61571)、[ガジェマガの運営解説](https://2week.net/23536/)、[ガジェ侍 広告掲載ポリシー](https://gadgetzamurai.jp/ad-policy/)、[UPDATE コンテンツ制作ポリシー](https://update.grapee.jp/content-policy)

## PTGLの最適運用

### 1. 入口で5分類する

記事や投稿を作る前に、次のいずれかを必須項目として記録する。

```text
commercial_relation:
  self_paid          # 自腹、収益リンクなし
  affiliate_only     # 自腹・自主制作、通常アフィリエイトのみ
  provided           # 商品提供・貸与・招待あり
  sponsored          # 報酬・指定投稿・特別施策あり
  own_product        # 自社商品・自社サービス
```

この1項目から、ブログ・X・YouTubeの表示を自動で出し分ける。

### 2. Xは「役立つ本文→CTA→正確な開示」

推奨構成:

```text
数字または失敗談のフック
実測結果と注意点（この投稿だけでも1つ得する）
記事URL
※記事内にアフィリエイト広告を含みます
#関連タグ1つ #関連タグ2つ
```

- 記事流入が目的ならURLは本文。認知実験をするときだけ返信リンクと比較する。
- 画像は1〜4枚。実写、同条件比較、内訳、失敗防止の順。
- タグは1〜2個。大量タグと短時間の類似投稿をしない。
- 企業案件は1行目を `【PR】提供：会社名` に置き、返信だけに表示しない。

### 3. ブログは「自腹・実測・欠点」を先に見せる

- 記事タイトル直下または導入前に `本記事にはアフィリエイト広告が含まれます` を表示。
- 自腹なら導入で `自腹購入` を明記。案件感を減らすためではなく、レビュー条件を伝えるため。
- 提供・貸与なら、提供会社・返却の有無・原稿確認の有無を記事上部に明記。
- 比較表には価格基準日、送料、工賃、オプション費用を含める。
- メーカー写真の転載より、実写・購入履歴・見積もり・実測値を主役にする。
- 長所だけでなく「向かない人」「失敗しやすい点」を必ず入れる。

### 4. YouTubeは3層で開示する

有償・商品提供あり:

1. YouTube Studioの「有料プロモーションを含む」をオン
2. 概要欄1行目に `【PR／提供：会社名】`
3. 動画内に小さな `PR／提供：会社名` 表示を継続、少なくとも冒頭・商品紹介中・CTA付近で再表示

通常アフィリエイトのみ:

```text
※概要欄の一部リンクはアフィリエイトリンクです。購入されると当チャンネルに紹介料が入る場合があります。
```

概要欄の順序は `開示→主商品リンク→結論／ブログリンク→チャプター→SNS` とする。

### 5. 30投稿で検証する

追う数字はフォロワー数より次を優先する。

| 指標 | 見る理由 |
|---|---|
| Xインプレッション | フックと画像の強さ |
| プロフィールクリック率 | 発信者への興味 |
| リンククリック率 | CTAと開示文の影響 |
| ブログ滞在・離脱 | 記事冒頭との整合 |
| 楽天クリック・成果 | 収益導線の質 |
| 返信・保存 | 実用性と信頼 |

最初の30投稿は一度に1変数だけ変える。優先テストは以下。

1. X本文リンク対返信リンク
2. 数字型対失敗談型
3. 実写1枚対「実写＋比較表」2枚
4. 開示文 `記事内に広告あり` 対 `記事内にアフィリエイト広告を含みます`

## 採用しない方法

- すべてを一律 `#PR` にして、企業案件と自腹レビューを区別不能にする
- 企業案件のPR表示を返信だけに置く
- 直接アフィリエイトリンクなのに、プロフィールの包括表示だけで済ませる
- 同じ商品リンクと同じ文面を短時間に連投する
- メーカー文言を言い換えただけのレビュー
- 長所だけを並べ、購入後の失敗条件を書かない
- YouTube概要欄で商品リンクを開示文より上に置く

## 今回のタイヤ記事・Xへの適用

今回のセレナC26タイヤ記事は、自腹購入・自主制作・通常の楽天アフィリエイトのみなので、企業案件を示す `#PR` は使わない。ただしXのプラットフォームポリシーへ合わせ、X本文のURL付近に次を置く。

```text
※記事内に楽天アフィリエイト広告を含みます
```

ブログ記事冒頭の `本記事には楽天アフィリエイト広告が含まれます` は維持する。これで「企業から依頼されたレビュー」ではないことと、「成果報酬リンクがある」ことを両立して伝えられる。
