タスク: $ARGUMENTS

CLAUDE.md「AI相互連携の課金制限」に従う。
実行前に、今回使うモデルをユーザーが明示しているか確認する。未指定なら「Codexに依頼するモデルはどれにしますか？」と会話で質問し、回答を待つ。既定設定や過去の別タスクから推測しない。
以下の共通窓口のコマンドには必ず `--model <ユーザーが選んだモデル>` を付ける。終了コード3はモデル選択待ちであり、自動補完・再試行は禁止。同じ壁打ち依頼の各往復では、確認済みの同一モデルを使う。
まず対象が小さく明確な実装か判断する。曖昧・大規模・破壊的なら分割してから依頼する。
`python3 tools/subscription_ai.py codex implement` の標準入力へタスクと変更対象を渡す。
タスクをシェルのコマンド文字列に展開せず、プロセスの標準入力として渡すこと。
直接のCLI・APIキー利用・別経路での再試行は禁止。失敗したら停止して報告する。
成功したら `git status --short` と `git diff` を読み、差分を検証してテストする。
既存のユーザー変更は破棄しない。実装内容・検証結果・残る問題を日本語で報告する。
