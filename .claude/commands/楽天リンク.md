`rakuten-link` スキル（`.claude/skills/rakuten-link/SKILL.md`）を起動してください。

商品1点の楽天アフィリエイトリンクを定型手順で取得します：

1. **台帳を先に確認**（`blog/MEMORY.md` 楽天リンク台帳。既存リンクは再生成せず流用）
2. Claude in Chrome で楽天市場検索 → **公式ストア優先・バリエーションを画面で確定**
3. affiliate.rakuten.co.jp（freelink）→ **短縮URLタブ**で `a.r10.to/xxxxxx` 取得
4. 台帳に記入 → 記事のカードに設置 → `article_lint.py --post <ID>` で点検

🚫 自分のリンクを自分でクリックしない／在庫「確保でき次第」の店は避ける
