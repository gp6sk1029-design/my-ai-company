# 楽天リンク取得スキル（2026-08-01 制定・実証済み手順の定型化）

商品1点の楽天アフィリリンク取得を、迷子なし・事故なしで行うための手順書。
2026-07 の実作業（hg5XXN／hYLZNi／hPo09t／hPCOQf）で確立したやり方をそのまま定型化した。

## 🔴 起動前チェック（毎回必須）

1. **台帳を先に見る**：`blog/MEMORY.md` の「楽天リンク台帳」を検索。
   **同じ商品のリンクが既にあれば再生成しない**（計測が分散するため）。既存を流用して終了。
2. Claude in Chrome が接続済みであること（ダメなら接続を依頼）。

## 手順（1商品あたり約5分）

### ① 楽天市場で商品ページを確定する
- `search.rakuten.co.jp` で商品名検索
- **公式ストア（メーカー直営）を最優先**。次点は大手家電（Joshin・ビック等）
- 🚫 在庫表記が「確保でき次第」「お取り寄せ」の店は避ける
- 🚫 **バリエーション（サイズ・色・型番）を画面で選択して確定**してから
  そのURLを使う。商品名が完全一致でも別サイズ・別モデルの罠がある
  （実例：MX ERGO Sで「大きいサイズ」の別商品、Venu 4で40mm/45mm）
- 価格・店名・在庫をメモしておく（台帳に書く）

### ② アフィリリンクを生成する
- `affiliate.rakuten.co.jp` → リンク作成（freelink）に商品URLを貼る
- **「短縮URL」タブ**に切り替えて `https://a.r10.to/xxxxxx` を取得
- 🚫 長いhtml形式のコードは使わない（記事のカードには短縮URLだけ）

### ③ 台帳に記入する（省略禁止）
`blog/MEMORY.md` の「楽天リンク台帳」へ1行追加：
```
| a.r10.to/xxxxxx | 商品名 | 店名 | 価格（取得日） | 使用記事ID |
```

### ④ 記事に設置する
- `:::product` カードの楽天ボタンに設置（書式は `blog/SKILL.md` §C）
- 設置後は `python3 blog/scripts/article_lint.py --post <ID>` で点検

## 🚫 禁止事項

- **自分で生成したアフィリリンクを自分でクリックしない**（規約違反）。
  動作確認はリンク先URLの目視とHTTPステータス確認まで
- 生成済みリンクの再生成（台帳を必ず先に見る）
- 検索結果やバリエーション未選択の親ページURLをそのまま使う
