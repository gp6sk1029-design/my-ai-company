## §1. SNS共通ルール

### 1.1 ブログ記事との連動
- ブログ記事の公開時に必ず3チャネル分の原稿を生成する
- 各原稿には記事URLを含める（短縮URLはbit.ly等は不要、WordPressのslugそのまま）
- 公開後24時間以内の投稿が望ましい（鮮度命）

### 1.2 共通の文体ルール
- 一人称：「僕」（オオタニ所長準拠）
- 工場・生産技術の現場感を出す（「工場では〜」「生産現場では〜」）
- 数字を必ず入れる（「3万円」「年間125時間」「月1,000円で〜」）
- 絵文字は使い分け（X：控えめ／Instagram：多め／YouTube：適度）

### 1.3 NG事項（全チャネル共通）
- 根拠のない誇張（「神」「最強」「絶対」）
- ステマ表記なしのPR
- ブログ記事と矛盾する内容
- 他社製品の感情的な批判

## §3. 原稿生成の標準フロー

### 入力
- ブログ記事のWP投稿ID（例：703）または記事ファイルパス
- 対象チャネル（指定なければ3チャネル全部）

### 処理
1. 記事本文・タイトル・キーアイディアを抽出
2. 各チャネルのSKILL.mdに従ってフォーマット
3. 金額換算・数字を冒頭に配置
4. ハッシュタグを規約通りに付与
5. オオタニ所長の語り口で校正

### 出力
- チャネル別の原稿ブロック（コピペで投稿可能な形式）
- 投稿予定時刻の提案（ブログ公開直後・翌朝7時・夜21時の3案）

### ユーザーからの指示例（Phase 1完成後の想定）
- 「**記事703のSNS原稿作って**」
- 「**XとInstagramのみで原稿作って**」
- 「**YouTube概要欄を記事703から作って**」

## §6. 自動投稿基盤（Phase 4・要エンジニア相談）

🚨 **このセクションはCLAUDE.md準拠で要エンジニア相談の領域**

### 構成（予定）
- インフラ：Cloudflare Workers + Cron Triggers + D1
- 認証：各SNSのOAuth（Cloudflare Secretsで管理）
- フロー：calendar.md → Worker読込 → API投稿 → D1記録

### 必須の前提作業（人間側）
- X Developer Portal アカウント取得
- Instagram Graph API（Facebook Business＋Instagram Business変換）
- YouTube Data API（Google Cloud Project作成）

### 安全ガード（CLAUDE.md準拠）
- APIキーは絶対にコードに直接書かない（Cloudflare Secrets必須）
- 「下書き保存→手動承認→投稿」の半自動方式から開始
- 完全自動化は運用ノウハウが溜まってから
