# 「生産技術ガジェット研究所」公式X運用ルール

> このSKILL.mdは `sns/SKILL.md` の§1共通ルールに従う前提。X固有の追加ルールのみを記述する。
> 旧 `blog/SKILL.md` §12 の内容を移管・拡張（2026-05-02）。

---

## §1. 基本仕様

| 項目 | ルール |
|---|---|
| 文字数 | 1投稿140字以内（厳守） |
| ハッシュタグ | 末尾に3〜5個 |
| 改行 | 読みやすい位置で2〜3箇所まで |
| URL | 末尾配置・記事URLは1つまで |
| 絵文字 | 控えめ（0〜2個） |

## §2. 投稿の3型（必ずこのいずれかを使う）

### 2.1 数字型（最頻出・拡散しやすい）
**冒頭に金額・時間・回数を置いて読者の関心を引きつける**

```
月1,000円で年間25万円分の時間を生み出すツールを見つけた。

工場勤務時代、毎日30分のムダ作業に悩まされていた僕が、
このツールに切り替えたら年間125時間が手に戻ってきた。

詳細はブログで解説した👇
[記事URL]

#ガジェット #時短 #効率化
```

### 2.2 裏話型（独自性・読者の好奇心刺激）
**「工場では絶対に教えてくれない〜」で始める**

```
工場では絶対に教えてくれない、効率化の本当の話をブログに書いた。

「便利なツールを買えば時短できる」は半分嘘で、
実は買ってから〇〇しないと逆に時間を失う。

その理由を生産技術視点で解説。
[記事URL]

#生産技術 #時短 #効率化
```

### 2.3 口コミ型（信頼性・E-E-A-T強化）
**Amazon・楽天の星1〜5を分析した独自視点で展開**

```
Amazon星1レビューを100件読んで気づいたこと。

「便利」と評価されているガジェットほど、
実はある条件を満たさないと逆に時間を奪われる。

100件分析した結論をブログにまとめた。
[記事URL]

#ガジェット #口コミ #費用対効果
```

## §3. ハッシュタグ運用

### 3.1 推奨タグ（記事ジャンル別）

| ジャンル | 推奨タグセット |
|---|---|
| ガジェット | `#ガジェット #時短 #効率化 #生産技術 #費用対効果` |
| 時短術 | `#時短 #効率化 #生産技術 #働き方改革 #業務改善` |
| AI | `#AI活用 #ChatGPT #Claude #効率化 #生産性向上` |
| アプリ・SaaS | `#効率化アプリ #時短 #SaaS #生産技術 #費用対効果` |
| 工場裏話 | `#工場 #生産技術 #現場のリアル #ものづくり` |

### 3.2 NGタグ
- `#フォロバ` `#相互フォロー` 系（ブランド毀損）
- 関連性のない大流行タグ（規約違反リスク）
- 一文に5個超え（冗長）

## §4. 投稿時刻の戦略

| 時間帯 | 用途 | 想定読者 |
|---|---|---|
| 7:00 | 朝の通勤前投稿 | 仕事前にチェックする層 |
| 12:00-13:00 | 昼休み投稿 | サラリーマン・主婦 |
| 21:00-22:00 | ゴールデンタイム | 帰宅後リラックス層 |

ブログ記事公開時：
1. **公開直後**：1投稿目（数字型）を即時投稿
2. **翌朝7時**：2投稿目（裏話型）で再リーチ
3. **その日の21時**：3投稿目（口コミ型）でクロージング

→ 1記事につき最大3投稿で多面展開。同一URLの連投はスパム判定リスクあるため、各投稿の文体は必ず変える。

---

## §5. 引用・スレッド・リプライの方針

### 5.1 スレッド化
記事の核心が長い時はスレッド化（最大3ツイート）
- 1ツイート目：結論＋数字
- 2ツイート目：理由・現場経験
- 3ツイート目：URL＋まとめ＋ハッシュタグ

### 5.2 引用RT
他者投稿の引用RTは原則禁止（炎上リスク）。情報源として活用したい時は、ブログ記事内で出典明記する形に留める。

### 5.3 リプライ
ファン・読者からの建設的コメントには返信。批判コメントへの反論は禁止（オオタニ所長は冷静沈着）。

---

## §6. 禁止事項（X固有）

- 140字超え（プラットフォーム制約・読者離脱）
- ハッシュタグ6個以上（読みづらい・SEO効果薄）
- 同じ文面の連投（スパム判定）
- 「いいねください」「RTお願いします」直接的依頼（プロらしくない）
- 政治・宗教・センシティブ話題への踏み込み

---

## §7. 振り返り観点（X固有）

投稿後3日のメトリクス：
- インプレッション数（目標：1投稿1,000以上）
- いいね数（目標：1投稿10以上）
- リンククリック率（目標：インプの2%以上）
- ハイパフォーマンス投稿は型をMEMORY.mdに記録 → 横展開
