## §0. 2026最新作法＆ハイブリッド運用（最重要・毎回確認）

### 0-1. 初動は「交流ファースト」（投稿より先）
- フォロワー0は投稿を投下しても読まれない。**まず同ジャンルへの良質リプで見つけてもらう**。
- 毎日リプ5〜10件＋投稿は週3〜5本で十分。詳細は [engage-list.md](engage-list.md)。
- 最初の30日のKPIは**フォロワー数でなく「インプレッション・プロフィールクリック・フォロー率」**。

### 0-2. 投稿はX内完結型に（記事誘導より先）
- 「記事を読ませる」より先に**「この投稿だけで1つ得する」**。リンク位置は**本文／返信を投稿目的ごとに選び、実測比較**する。
- X公式は本文へのURL掲載を正式に案内しており、URLは長さに関係なくt.coの23文字として数える。本文リンクが自動的にリーチ低下するという公式根拠はないため、「返信なら安全」と固定視しない。
- **実機写真・設定スクショ・比較表を必ず添付**（メディア付きが優先表示）。
- ROIの数字には**前提を1行**添える（例「前提：1日12分短縮×時給950円換算」）。根拠なし数字はツッコミ炎上の的。

### 0-3. 炎上回避の鉄則
- 良い点と気になる点を**必ず両方**書く（両論併記）。
- 「神」「最強」「絶対」など断定表現を使わない。
- アフィリ・提供品は**【PR】を目立つ位置**＋**「リンク先に広告を含みます」をプロフ・固定ポストに明記**。
- 批判リプには反論せず原則スルー（オオタニ所長は冷静沈着）。
- 他社製品をけなさない／政治・宗教・センシティブ話題に触れない／無関係な流行タグに便乗しない。

### 0-4. ハイブリッド運用（凍結回避・役割分担）
**「リプ自動化」と「同一文面の定期連投」がXの凍結の筆頭** → そこは人間に残す。

| 作業 | リスク | 担当 |
|---|---|---|
| 原稿・リプ案の作成、画像準備、分析、台帳記録 | なし | 私（AI） |
| プロフ設定・画像反映（開設直後の一括設定） | 低 | 私（Claude in Chrome・目視同席） |
| 投稿の下書き入力（文面＋画像セット） | 低 | 私（Claude in Chrome） |
| 投稿の「送信」ボタン | 中 | あなた（目視で最終クリック） |
| リプ（交流）の送信 | **高** | あなた（自分の言葉で。AIは案提示のみ） |

- 段階拡大：開設1ヶ月＋運用が安定したら投稿の送信もAI代行可。リプ送信は当面ずっと人間中心。
- 人間らしさ：同一文面を連投しない／間隔をあける／毎回少し変える。

### 0-5. X Premiumの購入判断（無料運用を先に検証）
- 開設・再始動直後は、Premiumを「表示回数が増えそう」という期待だけで契約しない。最初の30日または30投稿までは無料版で、投稿頻度・交流・プロフィールクリック率を改善する
- Basicは、投稿後の誤字修正や長文投稿が月2回以上の実ボトルネックになった場合に検討する
- Premiumは、青いチェック、Media Studio、クリエイター機能を実際に使う段階で検討する。契約前に月額を回収できる導線（ブログクリック・アフィリエイト成果）を確認する
- 有料化の前後で表示数・プロフィールクリック率・リンククリック率を記録し、効果が確認できなければ更新しない

## §2. 投稿の3型（必ずこのいずれかを使う）

### 2.0 X拡散セット（ブログ記事の標準形）

ブログ記事からXへ誘導するときは、文章だけで終わらせず次の一式を作る。

1. **訴求分析**：実測数字・意外性・失敗防止のうち、最も強い1点を決める
2. **本文**：X換算140字以内、ハッシュタグは原則1〜2個。この投稿だけでも1つ得する内容にする
3. **リンク戦略**：`reply`（認知優先）か `main`（ブログ流入優先）を明示。mainの場合は本文に【PR】＋記事URLを入れる
4. **画像1〜4枚**：①数字フック ②同条件比較 ③費用/手順の内訳 ④注意点・失敗防止
5. **投稿画面の準備**：本文と画像をセットする。最後の「ポストする」と返信送信はユーザーが行う

画像は1200×1200pxを標準とし、長辺1800pxを超えない。数字は記事中の確定値だけを使い、比較条件と基準日を小さく併記する。4枚すべてを埋める情報がない場合は無理に水増しせず1〜3枚に減らす。

### 2.1 数字型（最頻出・拡散しやすい）
**冒頭に金額・時間・回数を置いて読者の関心を引きつける**

```
月1,000円で年間25万円分の時間を生み出すツールを見つけた。

工場勤務時代、毎日30分のムダ作業に悩まされていた僕が、
このツールに切り替えたら年間125時間が手に戻ってきた。

比較条件と失敗しやすい点は画像にまとめました。

#ガジェット #時短
```

### 2.2 裏話型（独自性・読者の好奇心刺激）
**「工場では絶対に教えてくれない〜」で始める**

```
工場では絶対に教えてくれない、効率化の本当の話をブログに書いた。

「便利なツールを買えば時短できる」は半分嘘で、
実は買ってから〇〇しないと逆に時間を失う。

その理由を生産技術視点で整理しました。

#生産技術 #時短
```

### 2.3 口コミ型（信頼性・E-E-A-T強化）
**Amazon・楽天の星1〜5を分析した独自視点で展開**

```
Amazon星1レビューを100件読んで気づいたこと。

「便利」と評価されているガジェットほど、
実はある条件を満たさないと逆に時間を奪われる。

100件を読んで見えた条件を図解にまとめました。

#ガジェット #口コミ
```

## §4. 投稿時刻の戦略

> 🆕 **最優先枠：火・水・木の朝8-10時／昼12-14時**（2026実測でエンゲージメント高）。投稿は週3〜5本で十分。メディア（写真/動画）添付を必須に。

| 時間帯 | 用途 | 想定読者 |
|---|---|---|
| 7:00 | 朝の通勤前投稿 | 仕事前にチェックする層 |
| 12:00-13:00 | 昼休み投稿 | サラリーマン・主婦 |
| 21:00-22:00 | ゴールデンタイム | 帰宅後リラックス層 |

ブログ記事公開時：
1. **公開直後**：1投稿目（数字型）を即時投稿
2. **翌朝7時**：2投稿目（裏話型）で再リーチ
3. **その日の21時**：3投稿目（口コミ型）でクロージング

→ 1記事につき最大3投稿で多面展開。同一URLの連投はスパム判定リスクあるため、各投稿の文体は必ず変える。

## §5. 引用・スレッド・リプライの方針

### 5.1 スレッド化
記事の核心が長い時はスレッド化（最大3ツイート）
- 1ツイート目：結論＋数字
- 2ツイート目：理由・現場経験
- 3ツイート目：URL＋まとめ＋ハッシュタグ

### 5.2 引用RT
他者投稿の引用RTは原則禁止（炎上リスク）。情報源として活用したい時は、ブログ記事内で出典明記する形に留める。

### 5.3 リプライ
ファン・読者からの建設的コメントには返信。批判コメントへの反論は禁止（オオタニ所長は冷静沈着）。

## §6. 禁止事項（X固有）

- 140字超え（プラットフォーム制約・読者離脱）
- ハッシュタグ6個以上（読みづらい・SEO効果薄）
- 同じ文面の連投（スパム判定）
- 「いいねください」「RTお願いします」直接的依頼（プロらしくない）
- 政治・宗教・センシティブ話題への踏み込み

## §7. 振り返り観点（X固有）

- インプレッション数（目標：1投稿1,000以上）

- リンククリック率（目標：インプの2%以上）
