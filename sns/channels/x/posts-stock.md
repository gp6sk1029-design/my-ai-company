### B-1. 生産技術の小ネタ ⬜
```
工場で叩き込まれた「段取り替え」の発想は家でも効く。

作業を止める原因を先に潰すと、手を動かす時間が増える。
ガジェットも「使う前の準備」が短い物ほど結局よく使う。

買って3日で使わなくなる物は、だいたい準備が面倒な物。

#生産技術
```

### B-2. ガジェット選びの判断軸 ⬜
```
ガジェットを買うか迷ったら、僕はこれで決めてます。

「1日に浮く分」×「年間使用日数」×「自分の時給」＝年間の価値。
これが本体価格を超えるなら買い。

“なんとなく便利”を金額に変えると、迷いが消えます。

#費用対効果
```

### B-3. 失敗談（共感型） ⬜
```
ガジェット沼で学んだこと。

「多機能で最強」より「1つの面倒を確実に消す」物の方が、結局ずっと使う。
機能が多い物ほど設定が複雑で、気づくと棚の肥やしに。

僕が毎日使う物は、どれも地味で単機能でした。

#ガジェット
```
