# YouTube特化SKILL.md
# 「生産技術ガジェット研究所」公式YouTubeチャンネル運用ルール

> このSKILL.mdは `sns/SKILL.md` の§1共通ルールに従う前提。YouTube固有の追加ルールのみ記述する。

---

## §1. 基本仕様

| 項目 | 通常動画 | ショート |
|---|---|---|
| 動画長 | 5〜15分推奨 | 60秒以内 |
| 解像度 | 1,920×1,080（横） | 1,080×1,920（縦） |
| タイトル | 100字以内（推奨50字以内） | 同左 |
| 概要欄 | 5,000字以内 | 同左（短くてOK） |
| サムネ | 1,280×720以上 | 自動生成または1,080×1,920 |
| タグ | 最大500字 | 同左 |
| チャプター | 必須（5分超なら） | 不要 |

---

## §2. タイトルの型（クリック率最大化）

### 2.1 数字＋具体性型
```
【年間8万円の差】HUAWEI GT Runner 2 vs Garmin Venu 2S｜ランナーが選ぶべきは？
```

### 2.2 検証・実証型
```
【10km実走データ】HUAWEI GT Runner 2を生産技術視点で本気レビュー
```

### 2.3 裏話・暴露型
```
工場では絶対に教えてくれない、効率化ツールの選び方【生産技術の本音】
```

### 2.4 NGタイトル
- 釣りタイトル（中身と一致しない）
- 全角記号過多（【】を3つ以上）
- 商品名のみ（検索意図不明）

## §4. サムネイルの設計指針

### 4.1 必須要素
1. **数字**を大きく（「年間8万円」「10km」「3万円」）
2. **製品の実機写真**（必要に応じてズームイン）
3. **キャッチコピー**（最大10字）
4. **チャンネルロゴ**（右下小さく）

### 4.2 配色
- ベース：白＋黒（視認性優先）
- アクセント：水色（#56CCF2、ブログ装飾と統一）
- 警告・否定要素：赤
- 推奨要素：緑

### 4.3 サムネ例
```
[実機写真（左側60%）] ｜ 【年間8万円の差】（右上・黒地白文字）
                     ｜ vs Garmin（右中央・赤文字）
                     ｜ ランナー必見（右下・水色）
```

### 4.4 NGサムネ
- 全部入り（情報過多）
- 顔だけアップ（チャンネル特性に不一致）
- 文字が小さい（スマホで見えない）

---

## §5. チャプター（タイムスタンプ）必須ルール

5分超の動画は必須。概要欄の冒頭に配置すれば自動でチャプター化される。

### フォーマット
```
00:00 オープニング
00:30 結論
02:00 〇〇
（最低5チャプター以上）
```

### NG
- `00:00 -- 1:30` のようなハイフン区切り（YouTube認識しない）
- 最初が `00:00` でない（必須仕様）
- チャプター名が長すぎる（30字以内推奨）

---

## §6. ショート動画の構成（60秒以内）

| 秒数 | 内容 |
|---|---|
| 0〜2秒 | 結論を強烈に（テキストオーバーレイ） |
| 2〜10秒 | 問題提起 |
| 10〜45秒 | 解決策・実演 |
| 45〜55秒 | 数値根拠（年間〇万円・〇時間） |
| 55〜60秒 | CTA（「詳細は概要欄から」「チャンネル登録」） |

### キャプション
- 1〜2行・簡潔に
- ハッシュタグ3〜5個

---

## §7. 投稿頻度・時刻の戦略

| 種別 | 推奨頻度 | 推奨時刻 |
|---|---|---|
| 通常動画 | 週1〜2本 | 金曜・土曜の20:00〜21:00（週末視聴枠） |
| ショート | 週3〜5本 | 12:00 / 19:00 / 22:00（スキマ時間枠） |

---

## §8. アフィリエイト・PR表記ルール

### 必須表記
- アフィリエイトリンクを概要欄に含める場合、冒頭に明記：
  ```
  ※本動画には Amazon アソシエイト等のアフィリエイトリンクを含みます。
  ```
- 提供PRの場合、動画冒頭5秒以内に「PR」表記＋概要欄にも明記。

---

## §9. 禁止事項（YouTube固有）

- 著作権侵害素材（音楽・画像・映像）
- 釣りタイトル＋低品質コンテンツ（ペナルティリスク）
- ステマ（PR表記なし）
- 他者攻撃・誹謗中傷
- 著作権申告ストライク回避のための切り抜き乱発

---

## §10. 振り返り観点（YouTube固有）

公開30日後のメトリクス：
- インプレッション数（YouTubeアナリティクスから）
- クリック率（CTR・目標：5%以上）
- 平均視聴時間（目標：動画長の50%以上）
- チャンネル登録者増加数
- ブログへの流入数（GoogleAnalytics連携）

→ CTR・視聴時間が高い動画パターンをMEMORY.mdに記録
