# Instagram特化SKILL.md
# 「生産技術ガジェット研究所」公式Instagram運用ルール

> このSKILL.mdは `sns/SKILL.md` の§1共通ルールに従う前提。Instagram固有の追加ルールのみ記述する。

---

## §1. 基本仕様

| 項目 | フィード投稿 | リール |
|---|---|---|
| キャプション | 2,200字以内（先頭125字が重要） | 同左 |
| ハッシュタグ | 最大30個（推奨：15〜25個） | 最大30個（推奨：10〜15個） |
| 画像 | 1,080×1,080（正方形）または1,080×1,350（縦長） | 9:16縦動画・最大90秒 |
| カバー画像 | 自動 | 必須（1,080×1,920） |
| 絵文字 | 多めOK（3〜10個） | 同左 |

---

---

## §3. リール（縦動画90秒）の構成

| 秒数 | 内容 |
|---|---|
| 0〜3秒 | 結論をテキストで強烈に提示（「年間25万円のムダ、知ってますか？」） |
| 3〜15秒 | 問題提起（読者の共感を呼ぶ） |
| 15〜60秒 | 解決策（ガジェット紹介・使い方・数値根拠） |
| 60〜80秒 | キャラ対話風カット（オオタニ＋タナカ） |
| 80〜90秒 | CTA（「詳細はブログ・プロフリンクから」） |

### リールキャプションは短く
- 冒頭1行で動画内容を要約
- ハッシュタグ10〜15個

## §4. ハッシュタグ運用

### 4.1 推奨タグセット（フィード用・15〜25個）

**コアタグ（毎回使う）**
```
#ガジェット #時短ツール #効率化 #生産技術 #ものづくり
```

**ジャンルタグ（記事に応じて選定）**
```
スマートウォッチ：#スマートウォッチ #ガーミン #HUAWEI #ランニング
時短SaaS：#SaaS #業務効率化 #リモートワーク
AI：#ChatGPT #Claude #AI活用 #生成AI
工場裏話：#工場 #現場のリアル #製造業 #改善活動
```

**コミュニティタグ（拡散・繋がり用）**
```
#ガジェット好きと繋がりたい #ライフハック #便利グッズ #買ってよかった
```

### 4.2 NGタグ
- `#follow4follow` `#like4like` 系（規約違反リスク）
- ボット系大量タグ
- 無関係タグ（ペット系等）

## §5. 画像・動画の品質基準

### 5.1 フィード画像
- 解像度：最低1,080×1,080（推奨1,440×1,440）
- ブログ記事のアイキャッチ画像を流用可（ただしInstagram用にトリミング）
- 4枚以上ある時はカルーセル投稿（左右スワイプ）

### 5.2 リール動画
- 解像度：1,080×1,920（9:16）
- フレームレート：30fps以上
- 字幕（テキストオーバーレイ）必須（音声OFF視聴対応）
- BGM：Instagramの推奨楽曲ライブラリから選定

### 5.3 ⚠️ 画像Read制限の遵守
ブログ部門と同じく、SNS原稿生成時もClaudeに画像を直接Readさせない。
- 画像分析が必要な場合はsubagent（Explore）に委譲
- 詳細：`blog/skills/technical.md`「画像の会話蓄積を防ぐ運用ルール」参照

## §6. 投稿時刻の戦略

| 曜日 | 推奨時間帯 | 用途 |
|---|---|---|
| 平日 | 12:00-13:00 / 19:00-21:00 | 通勤・帰宅後のスマホ閲覧時間 |
| 土日 | 10:00-12:00 / 20:00-22:00 | 休日のリラックスタイム |

リールはストーリーズと違い「時間を選ばない」傾向あり。アルゴリズムに任せる前提でゴールデンタイムに集約。

---

## §7. 禁止事項（Instagram固有）

- ハッシュタグ31個以上（規約違反）
- 著作権不明の音楽・画像使用
- 直接的なURL誘導（リンク貼っても踏まれない仕様）→ 必ず「プロフィールから」と誘導
- ステマ表記なしのPR（PRタグ必須）
- 同じキャプションの連投

---

## §8. 振り返り観点（Instagram固有）

投稿後7日のメトリクス：
- リーチ数（目標：1,000以上）
- 保存数（目標：10以上・最重要指標）
- プロフ訪問→外部リンククリック数
- リール再生完了率（目標：50%以上）

→ 保存数が高い投稿の型をMEMORY.mdに記録
